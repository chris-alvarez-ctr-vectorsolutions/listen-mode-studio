# Production guide

The rules every module script follows. Read this before any stage.

**Order of authority.** Facts come only from the signed claims ledger. The hard rules in this guide come next. The pattern library decides how a part is shaped. The voice example sets register only: how the hosts sound, never the structure, sequence, questions or lines of a script. If two of these seem to disagree, the earlier one wins. Example wording anywhere in the kit shows a move; never reuse it as a line.
